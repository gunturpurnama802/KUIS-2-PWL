# Tugas Kuis 2 PWL

Project frontend sederhana menggunakan Next.js untuk tugas Kuis 2 Pemrograman Web Lanjut.

## Cara Menjalankan

1. Install dependency:
   ```bash
   npm install
   ```

2. Jalankan server:
   ```bash
   npm run dev
   ```

Buka [http://localhost:3000](http://localhost:3000) di browser.
